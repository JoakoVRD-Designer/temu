# Plan Ganga

Plan para la oferta "Toma tu ganga" de Temu en Chile: tablet Teclast P50 a $0,
domingo 25 de octubre de 2026 a las 21:00 (hora de Chile).

- `plan-ganga.html`: página con cuenta regresiva, listas para marcar y plan B.
  Publicada (privada) en https://claude.ai/artifact/JwUgC17qNifjaEXwn9QKzj
- `recordatorio-temu-tablet.ics`: evento de calendario de 20:55 a 21:05, con avisos
  a las 20:40 y 20:55. Se abre en el teléfono para agregarlo al calendario.
